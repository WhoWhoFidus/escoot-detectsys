# Модуль детекции и отслеживания объектов для проекта СИМ

## 1. Назначение

Модуль принимает видеозапись с камеры СИМ, обнаруживает участников движения,
сопоставляет объекты между кадрами с помощью ByteTrack и сохраняет:

- видео с рамками, классами и ID объектов;
- CSV-файл с координатами рамок, центрами объектов, временем, классами и ID.

На первом этапе используется готовая YOLOv8n, обученная на COCO. Это позволяет
проверить конвейер без обучения собственной модели детекции.

## 2. Важное ограничение классов

COCO содержит классы person, bicycle, car, motorcycle, bus и truck, но не имеет
отдельного класса электросамоката. Класс motorcycle не следует автоматически
считать электросамокатом. Для надёжного распознавания СИМ понадобится собственный
датасет и дообучение модели.

## 3. Установка

Рекомендуется Python 3.10 или 3.11 в отдельном виртуальном окружении.

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если команда активации заблокирована политикой PowerShell, можно запустить:
`.venv\Scripts\python.exe -m pip install -r requirements.txt`

## 4. Структура папки

```text
sim_object_tracking/
    requirements.txt
    detect_track.py
    inspect_segmentation.py
    README_RU.md
    best.pt                 # положите сюда ваши веса сегментации
    video.mp4               # тестовое видео
```

## 5. Сначала проверьте вашу сегментацию

Положите `best.pt` рядом со скриптом и выполните:

```powershell
python inspect_segmentation.py --weights best.pt
```

Скрипт выведет фактические названия классов, сохранённые в модели.
Чтобы проверить предсказание:

```powershell
python inspect_segmentation.py --weights best.pt --source test.jpg
```

Необходимо убедиться, что оба класса отображаются корректно. Если среда, в которой
обучалась модель, использовала изменённую версию Ultralytics, может понадобиться
установить именно совместимую версию пакета.

## 6. Запуск детекции и трекинга

Положите тестовый ролик `video.mp4` в папку проекта:

```powershell
python detect_track.py --source video.mp4
```

При первом запуске Ultralytics может скачать `yolov8n.pt`. Для этого нужен интернет.
После загрузки веса можно использовать локально.

Результаты появятся в:

```text
runs/tracking/video_tracked.mp4
runs/tracking/video_tracks.csv
```

Полезные параметры:

```powershell
python detect_track.py --source video.mp4 --conf 0.35 --imgsz 640
python detect_track.py --source video.mp4 --model yolov8s.pt
python detect_track.py --source video.mp4 --device cpu
```

Если компьютер имеет совместимую NVIDIA GPU, обычно можно не указывать `--device`:
Ultralytics попробует выбрать доступное устройство автоматически.

## 7. Что означают данные CSV

- `frame` — номер кадра;
- `time_sec` — время от начала видео в секундах;
- `track_id` — ID отслеживаемого объекта; значение -1 означает, что ID не присвоен;
- `class_id`, `class_name` — класс COCO;
- `confidence` — уверенность детекции;
- `x1,y1,x2,y2` — координаты рамки;
- `center_x,center_y` — центр рамки.

ID ByteTrack не является постоянным идентификатором человека: при перекрытии,
потере объекта или повторном обнаружении ID может измениться.

## 8. Как это соединить с вашей сегментацией

На следующем этапе оба модуля должны получать один и тот же кадр:

1. Сегментация возвращает маски тротуара и велодорожки.
2. Детектор возвращает рамки объектов.
3. Трекер возвращает ID и историю координат.
4. Аналитический модуль сопоставляет объекты с областью движения и анализирует
   изменение их положения во времени.

Для TTC нельзя просто делить расстояние между центрами рамок на скорость камеры.
Нужно оценивать относительное движение, учитывать геометрию сцены и проверять,
могут ли траектории привести к сближению. Результат на первом этапе следует
называть оценочным TTC.

## 9. Ограничения первой версии

- COCO не содержит отдельного класса электросамоката.
- Детекция в рамке не гарантирует точного положения точки контакта объекта с землёй.
- ByteTrack может терять ID при сильных перекрытиях.
- Один видеопоток с движущейся камерой не даёт автоматически точную скорость в м/с.
- Не следует использовать результат как доказательство нарушения ПДД или
  неизбежности столкновения.

Сначала проверьте пайплайн на нескольких коротких роликах при хорошем освещении.
Затем отдельно оценивайте качество детекции и устойчивость ID-трекинга.
